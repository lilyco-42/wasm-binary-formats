APK 解包与网页资源运行

上传 .apk / .zip，在浏览器里列出条目；assets/ 下的网页资源可以直接在沙箱里跑起来。.exe / .dll 走 PE 头解析，只读不运行。其余常见二进制（tar / ar / deb / cab、gz / xz / bz2 / lz4 / zst、RIFF 与 TIFF、Matroska / WebM / MP4 家族、FLAC / MP2 / MP3 / Ogg / WAVE、MPEG-TS 节目表、PDF 页树、WebAssembly 模块段表、字体（含 WOFF2 表目录）、图标目录、Apple 二进制属性列表（对象表与引用图）、QOI 像素块流、JPEG 2000 盒子与 ihdr 字段、NumPy 数组头、HDF5 超级块与内部指针、Avro 容器块链、Arrow IPC 消息封包与文件块索引、docx / xlsx / pptx / odt / epub 包）会走结构解析，把头部字段、成员表与页树逐行列出来——读结构，不解码像素、不渲染文档、不执行任何代码。文件不上传，解包与解析都在 WebAssembly 内完成。

条目

    预览 / 运行

    选中左侧一个条目。HTML 条目会在隔离 iframe 中运行。

    隔离方式：sandbox="allow-scripts" 且不给 allow-same-origin，因此被解出来的页面拿到的是独立的不透明源，读不到本站的 cookie、localStorage 或同源文档。相对引用一律改写成 data: URL —— blob: 在 Chromium 里会被存储键规则挡住，隔离中的页面取不到宿主生成的 blob。勾选"允许运行脚本"关闭时，脚本一并禁用。Chrome 还会额外执行帧内 CSP，把 fetch/XHR、嵌套 frame 与 worker 禁掉；不支持 csp 属性的浏览器只剩 sandbox 这一层，脚本仍可自行发起网络请求。
